# Benchmark dataset

A reproducible benchmark for onboard "process, store or transmit" decisions. The **orbit geometry is real**, and the
**instrument workload is synthetic**:

- **Orbit geometry (real).** Passes and eclipses come from the Sentinel-2A TLE of 2026-09-26 (CelesTrak, NORAD 40697),
  propagated with SGP4 in skyfield. Passes are computed over CNES Toulouse (approx. 43.56° N, 1.48° E) at 10° and 20°
  elevation masks. Eclipses come from the JPL DE421 ephemeris.
- **Instrument workload (synthetic).** It is generated from the illustrative data types in `scenarios.json`.

The dataset is generated by `python -m satsched.cli dataset --seeds 3 --out data`. It is identical to what the
simulator uses for the same scenario and seed; each seed is a different real day.

```
data/
  orbit/
    sentinel2a.tle                   the TLE used (3-line format)
    sentinel2a_toulouse/             62 days of real geometry: geometry.json (provenance), passes.csv, eclipses.csv
  scenarios.json                     all parameters of the 6 scenarios (satellite, orbit, data types)
  <scenario>/seed_<NNN>/
    items.csv                        every data item acquired during the 24 h run
    contact_windows.csv              ground-station passes (downlink opportunities)
    eclipses.csv                     eclipse intervals (no solar power)
```

## `items.csv`

| Column | Unit | Meaning |
|---|---|---|
| `id` | – | item identifier, in acquisition order |
| `kind` | – | `optical_image`, `hyperspectral_cube`, `event_candidate`, `science_log`, `telemetry` |
| `created_s` | s | acquisition time from the start of the run |
| `raw_size_mb` | MB | raw size |
| `base_value` | value units | priority of this acquisition (value if delivered instantly at full fidelity) |
| `p_useful_estimate` | 0–1 | onboard estimate that the content is useful (e.g. cloud-free, true event) |
| `useful_truth` | 0/1 | **hidden ground truth**, revealed to the simulator only when the item is processed or delivered |

## `contact_windows.csv`

| Column | Unit | Meaning |
|---|---|---|
| `start_s`, `end_s` | s | pass start and end |
| `rate_mb_s` | MB/s | downlink rate during the pass |

## `eclipses.csv`

| Column | Unit | Meaning |
|---|---|---|
| `start_s`, `end_s` | s | interval in Earth's shadow |

Data types, value decay, processing costs and product sizes are listed in `scenarios.json` and explained in the
paper (`docs/paper`). Policies must never read `useful_truth`. It exists so that results can be evaluated and
reproduced.
